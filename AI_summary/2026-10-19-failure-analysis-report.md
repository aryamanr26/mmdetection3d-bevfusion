## Matching verification

- Coordinate frame: LIDAR_TOP / model LiDAR frame
- GT box convention: nuScenes center origin converted with LiDARInstance3DBoxes(..., origin=(0.5,0.5,0.5)) to bottom-center
- Pred box convention: detector pred_instances_3d boxes already bottom-center
- Class rule: same class only after remapping info categories -> model classes
- Matcher: greedy one-to-one by descending 3D IoU; each pred and each GT used at most once per frame
- One-to-one check: every TP uses a unique pred index and unique GT object_id within each frame (True)
- `num_lidar_pts` source: nuScenes info instances[].num_lidar_pts on the keyframe
- Sparse threshold: ≤ 5 annotated LiDAR points
- Tagging policy: multi-label on unique object_id; tag totals may overlap and must not be summed as disjoint counts
